MILESNATION — RUN CLUB EDITION

A responsive virtual running challenge landing page with a race-inspired forest green, high-visibility lime, and warm bone palette.

FEATURES
- Responsive desktop and mobile layouts with mobile navigation and sticky registration bar
- Running-only hero and gallery photography (no swimming imagery)
- Animated hero entrance, floating hero image, hover image zoom, staggered scroll reveals, CTA shine, animated trust ticker, and scroll progress indicator
- Challenge cards, FAQ accordions, WhatsApp shortcut, and pace calculator
- Reduced-motion accessibility support

SETUP
1. Extract this ZIP folder.
2. Open index.html in a browser or VS Code (Live Server recommended).
3. Replace all {{PLACEHOLDER}} values with real challenge, pricing, checkout, shipping, contact, and policy details before publishing.

Images and Google Fonts are loaded from the internet, so an internet connection is required for those assets.
